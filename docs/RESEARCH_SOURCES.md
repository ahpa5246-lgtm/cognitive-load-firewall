# Research sources

- CDC, HEADS UP: concussion information and recovery guidance: https://www.cdc.gov/heads-up/
- CDC, Managing Return to Activities: https://www.cdc.gov/heads-up/guidelines/returning-to-activities.html
- CDC, Signs and Symptoms of Concussion (danger-sign wording only): https://www.cdc.gov/heads-up/signs-symptoms/index.html

These sources inform safety wording only. The English and Arabic lexical patterns are conservative stop/pause triggers for a demo accessibility flow; they are not diagnostic criteria, translated emergency instructions, or a substitute for local qualified care. Interface Load Estimate values are experimental software heuristics, not clinical measurements.
